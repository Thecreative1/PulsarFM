Liga as peças certas

Confirma a compatibilidade da interface com o computador, o sistema operativo e o programa de gravação. Conta as entradas de microfone e de instrumento de que precisas em simultâneo, em vez de olhar só para o número total de ligações.

Para um microfone XLR, verifica a entrada necessária e, quando aplicável, a alimentação indicada pelo fabricante. Põe no orçamento o cabo, o suporte e os auscultadores: ninguém se lembra deles até fazerem falta.

  • Verifica os requisitos do software incluído e a duração de eventuais licenças.
  • Confirma as saídas para auscultadores e colunas.
  • Procura informação sobre monitorização direta se vais gravar voz ou instrumentos.

O atalho USB

Se só vais gravar voz, seja podcast, locução ou a guia da próxima demo, um microfone USB dispensa a interface. Ligas ao computador e está feito.

O preço é a flexibilidade: não dá para ligar uma guitarra nem um segundo microfone ao mesmo tempo. Se isso já está nos planos, começa pela interface. Se não está, o atalho poupa dinheiro e cabos.

O quarto também entra na gravação

Ouve o silêncio do quarto antes de comprar. Ventoinhas, trânsito e as reflexões das paredes entram na gravação. Mudar o microfone de sítio ou gravar a outra hora pode mostrar-te o que realmente falta.

Começa com uma cadeia simples que consigas dominar. Hoje um portátil faz o que há umas décadas pedia uma sala cheia de equipamento; o que não vem incluído é saber usá-lo. Acrescenta peças quando esbarrares numa limitação concreta.

Perguntas frequentes

O que preciso para montar um home studio?

Para começar: computador, um programa de gravação (DAW), um microfone e auscultadores fechados. Se o microfone for XLR ou quiseres gravar guitarra, junta uma interface de áudio. Os monitores podem esperar pela fase da mistura. Começa pequeno: o resto chega quando bateres numa limitação concreta.

Microfone USB ou XLR: qual escolher?

O USB liga direto ao computador e é o caminho mais curto para gravar voz. O XLR pede uma interface, mas permite trocar de microfone e gravar várias fontes. O Samson Q2U tem as duas saídas: começas por USB e passas a XLR quando comprares a interface, sem deitar nada fora.

Preciso de interface de áudio para gravar guitarra?

Sim. A guitarra precisa de uma entrada de instrumento (alta impedância), que o computador não tem. A Focusrite Scarlett Solo tem uma, ao lado da entrada de microfone, por isso dá para gravar voz e guitarra com a mesma caixa, uma de cada vez.

Auscultadores ou monitores para misturar?

Para gravar, auscultadores fechados: o som não passa para o microfone. Para misturar, os monitores mostram melhor como a música soa numa sala. O ideal é usar os dois e confirmar a mistura em ambos, e já agora no telemóvel, que é onde muita gente a vai ouvir.

Posso usar auscultadores Bluetooth para gravar?

Para ouvir, sim. Para gravar, não: o Bluetooth acrescenta atraso e ficas a cantar fora de tempo com o que estás a ouvir. Usa o cabo. Os ATH-M50xBT2 têm as duas ligações, por isso servem para as duas coisas.

Antes de decidir

Planeia uma primeira gravação possível, com todas as ligações resolvidas. Uma demo imperfeita gravada vale mais do que o estúdio perfeito que continua no carrinho.
